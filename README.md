# 🎓 GenAI Interactive Course

An interactive learning platform built with **React + Vite**, designed to deliver lessons, case studies, quizzes, and summaries in a simple and engaging way.  

Deployed on **Vercel** for fast and reliable hosting.

---

## 📌 Features
- 📚 Multi-lesson structure (Intro, Deep Dive, Case Study, Quiz, Summary).
- ✅ Interactive quizzes (MCQs with instant feedback).
- 🔄 Restart option at the end of the course.
- ⚡ Built with **Vite** for fast development.
- ☁️ Easy deployment with **Vercel**.
